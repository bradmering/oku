## Use the editor

```bash
npm run dev          # then /edit/white-rim
```

`SITE_PASSWORD` in your local `.env` gates dev too — unlock once, or comment it out (the middleware
fails open without it, which is what local dev wants).

The editor (`decisions/0021`, `0022`) is **dev-only and always will be until there is auth** — it
writes YAML to the local disk, so it 404s in production along with `/camera` and `/preview`. It:

- lists the thread, marking articles with no prose;
- **edits headings and prose in place on the rendered page** — the preview is the canvas;
- cuts and captions photographs on a contact sheet, and promotes one to hero;
- places panorama annotations by clicking the image;
- shows a `move`'s keyframe when you click its inline `⟶ move` marker.

**Re-running ingest is safe** (`decisions/0020`). It refreshes `sources` and `stage` and preserves
everything authored — prose, captions, culls, hand-tuned cameras, chapter order. `--scaffold`
regenerates from scratch and discards all of that.

## What was hard, and is now solved

Kept because the *reasons* still matter — the full list is `spec/09-white-rim-friction.md`.

- **FIT needed no dependency.** `lib/ingest/fit.ts` is ~150 lines of `DataView` maths, no Node APIs,
  runs in a browser or Worker. Before adopting a parser, check what fraction of a format you
  actually consume — here it was under 5%.
- **EXIF offset first, `--tz` as fallback.** 67 files carry `OffsetTimeOriginal`; 17 do not. The
  Brooks Range rule ("photos never carry an offset") was true of that camera only.
- **iPhone video is HEVC** — Safari plays it, Chrome and Firefox don't. Everything is transcoded.
- **37 of 39 "videos" were Live Photos.** Pairing, not duration, is the discriminator: the shortest
  real clip is 5.4s and two Live Photos run 3.2s.
- **"Max edge" is the wrong knob for a panorama.** A 2400px cap crushed 14404×3864 originals to
  2400×644. Panoramas cap *height* instead.
- **`getCloudflareContext()` throws** outside the Cloudflare adapter rather than returning an empty
  env — which is why media 404'd in `next dev` for so long. It now falls back to reading `.media/`.

## What is still open

- **A block inserter.** There is no way to add a chapter in the editor. `0021` argued against a
  palette from this scaffold; that was true of *this document* and does not generalise
  (`0022`). This is the next real gap.
- **Capturing a camera from the preview's own map** — the inspector links to `/camera/<slug>` in
  another tab instead. The stage would need to become interactive while a move is selected.
- **Inline prose editing assumes rendering is a split, not a transform.** The renderer does not
  process markdown, so text round-trips literally. `scripts/test-prose.ts` fails the day a markdown
  processor is added, which is the intended tripwire — `01-data-model.md` still has "text flavour —
  markdown, but which" open.
- **A `route` title and a flyover are incoherent together** (one draws the whole line, the other
  refuses to). Nothing stops you using both.
- **`Reveal` scroll animations** — deliberately deferred. Scroll already drives the camera
  continuously; a second scroll-triggered animation may read as busy. Try it, don't assume parity is
  right.
- **Per-chapter authorship.** Multi-person composition is the differentiator and `authors` lives
  only on the trip. White Rim has two authors and a leg that is genuinely Mark's.

```bash
                        # merge, edit-ops, prose — then fixture conformance

                        # SAFE to re-run: merges with authored work (0020)
npm run migrate         # legacy → fixtures/migrated (idempotent)
npm run upload-media    # needs `npx wrangler login`; MEDIA_SOURCE is a colon-separated list
bash scripts/convert-media.sh ../whiterim/photos --slug white-rim
```

- **Fixtures are the contract.** Format change ⇒ a fixture in `fixtures/forward/` in the same PR.
- `fixtures/legacy/` is **evidence, not authority** (`decisions/0011`). Don't design backwards from
  three old blog posts.
- Every PR gets a preview URL. **Craft is the differentiator** (`decisions/0009`) — review means
  opening it and looking, not reading a diff.
- **Never commit or push without an explicit green light.** Open PRs; a human merges.
- Stacked PRs: retarget the child *before* merging the parent, and don't `--delete-branch` a branch
  another PR is based on — it closes the child rather than retargeting it.
